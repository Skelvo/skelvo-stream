Le titre, l'artiste et la pochette de ce que tu écoutes s'affichent sur ton stream. Ça marche avec Spotify, Deezer, YouTube Music, Apple Music… grâce à Last.fm.

Relier ta musique
  1. Crée un compte gratuit sur last.fm.
  2. Dans les réglages de Last.fm, onglet Applications, connecte Spotify (ou installe le scrobbler de ton appli de musique). Astuce : fais-le sur ordinateur, c'est plus fiable que sur téléphone.
  3. Entre ton pseudo Last.fm ci-dessous. C'est tout !

Ton lien pour OBS

  1. Dans OBS, clique sur + dans Sources, puis choisis Navigateur.
  2. Colle le lien dans URL et règle la taille sur 700 × 140.
  3. La musique se met à jour toute seule toutes les 12 secondes. Si elle s'arrête, le widget se cache (si l'option est cochée).
Pourquoi Last.fm et pas Spotify directement ? Depuis 2025, Spotify réserve son API aux grandes entreprises. Last.fm est gratuit et marche avec presque toutes les applis de musique.
