Ton lien pour OBS

  1. Dans OBS, clique sur + dans Sources, puis choisis Navigateur.
  2. Colle le lien dans URL et règle la taille sur 700 × 260.
  3. Le minuteur démarre en pause : lance-le en tapant !timer start dans ton tchat.
  4. Le temps restant est mémorisé dans OBS : si OBS plante ou redémarre, il reprend là où il en était.
    Ces commandes marchent pour toi et tes modos. Le temps continue de s'écouler même si OBS est fermé, comme un vrai subathon.
