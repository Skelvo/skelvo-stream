Ton lien pour OBS

  1. Dans OBS, clique sur + dans Sources, puis choisis Navigateur.
  2. Colle le lien dans URL et règle la taille sur 640 × 640.
  3. Coche une case avec !bingo 5 (retape-la pour la décocher), plusieurs d'un coup avec !bingo 3 7 12, et vide la grille avec !bingo reset. Les cases cochées sont mémorisées.
