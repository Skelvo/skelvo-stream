Ton lien pour OBS

  1. Dans OBS, clique sur + dans Sources, puis choisis Navigateur.
  2. Colle le lien dans URL et règle la taille sur 600 × 300.
  3. Pour que ton stream entende les sons, coche Contrôler l'audio via OBS dans les propriétés de la source.
  4. Points de chaîne : avec ta chaîne connectée, crée une récompense par son (ex. « Klaxon ») et c'est tout. Sans connexion : une récompense « Jouer un son » avec un texte obligatoire, où le viewer tape le nom du son.
