Ton lien pour OBS

  1. Dans OBS, clique sur + dans Sources, puis choisis Navigateur.
  2. Colle le lien dans URL et règle la taille sur 1000 × 500.
  3. Mets la source au-dessus de ton jeu. Pour entendre les sons, coche Contrôler l'audio via OBS dans les propriétés de la source.
  4. Les alertes passent une par une : si 10 personnes s'abonnent d'un coup, personne n'est oublié.
